# Detoch More — rediseño visual

## Abrir esta versión

En Windows, ejecuta `INICIAR_VERSION_NUEVA.bat`.

La versión nueva usa el puerto **3015** intencionalmente para que un servidor viejo que siga abierto en `localhost:3000` no muestre el diseño anterior.

URL directa: `http://localhost:3015/proyectos`

## Proyectos

El apartado fue reconstruido desde cero con una lógica editorial: hero fotográfico, marquee, bloques narrativos, imágenes a sangre, composiciones asimétricas controladas y una selección reducida de fotografías. No utiliza la antigua cuadrícula/masonry.
